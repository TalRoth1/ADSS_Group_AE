## סקירה כללית  
Super Lee היא מערכת ניהול כוללת לפעילות סניפי סופר, המשלבת ניהול עובדים וניהול משלוחים בצורה יעילה, אמינה ונוחה למשתמש.

## הוראות לעובדים ונהגים

### לכלל העובדים
1. **כניסה למערכת**
   - התחברו באמצעות מזהה עובד וסיסמה
   - המערכת תציג אוטומטית אפשרויות בהתאם לתפקידכם

2. **ניהול המשמרות**
   - הצג במסך את המשמרות הקרובות שלך 
   - הגדר העדפות למשמרות ע"י בחירת משמרות פנויות
   - בדוק את המשמרות שהוקצו לך, והתפקיד ששובצת לבצע.

3. **צפייה במידע האישי **
   - גש לפרטים האישיים שלך
   - בדוק את יתרת ימי החופשה והמחלה
   - צפה בתפקידים ובמשמרות שלך

## מודולים במערכת

### מודול עובדים

#### תכונות:
- **ניהול תפקידי עובדים**
  - לכל עובד יכולים להיות מספר תפקידים (לפחות אחד)
  - הרשאות גישה לפי תפקיד
  - תפקידים נתמכים: מנהל משמרת, נהג, מחסנאי, קופאי

- **ניהול משמרות**
  - יצירת שני סוגי משמרות:  בוקר וערב 
  - שיבוץ מנהל משמרת
  - מעקב אחר זמינות עובדים
  - ניהול העדפות עובדים למשמרות
  - שיבוץ נהגים להובלות

- **ניהול נתוני עובדים**
  - ניהול פרטים אישיים
  - מעקב אחר שכר והטבות
  - ניהול ימי חופשה וימי מחלה
  - ניהול פרטי חשבון בנק

- **בקרת גישה**
  - מערכת התחברות מאובטחת
  - הרשאות לפי תפקיד
  - מעקב אחר פעילות עובדים

### מודול ניהול משלוחים

#### תכונות:
- **ניהול הובלות**
  - יצירת הובלות ומעקב אחריהם
  - שיבוץ משאיות
  - ניהול לוחות זמנים להובלות
  - מעקב אחר סטטוס משלוח:  *(ממתין, מאושר, נשלח, בעיה, בוטל, הושלם)*

- **ניהול מיקומים**
  - הוספת יעדים חדשים ופרטי איש קשר ביעד
  - חלוקה לפי אזורים (zones)

- **ניהול פריטים**
   -הוספת פריטים חדשים ומשקלם

-**ניהול משאיות**
  -הוספת משאיות

### ארכיטקטורת המערכת
- שכבת דומיין (Domain Layer): מימוש הלוגיקה העסקית
- שכבת נתונים (Data Layer): תקשורת עם מסדי נתונים, כולל אובייקטים להעברת נתונים בין שכבות
- שכבת ממשק משתמש (Presentation Layer): תצוגה וקלט מהמשתמש

### ספריות ותלויות מרכזיות
- Java SQL (JDBC) – לפעולות מול בסיס הנתונים
- Java Time API – לניהול תאריכים וזמנים (LocalDate)
- Java Collections Framework – למבני נתונים כמו HashMap ו־ArrayList

   - השתמש במאפייני המערכת לפי התפקידים שלך

## הנחיות שימוש למנהל כוח אדם או מנהל הובלות

### ניהול עובדים
1. **יצירת עובדים**
   - גיוס עובדים חדשים
   - הקצאת תפקידים
   - הגדרת מערך שעות עבודה

2. **ניהול משמרות**
   - יצירה וניהול של משמרות
   - שיבוץ עובדים למשמרות
   - אחריות על משמרת (עבור מנהל משמרת)

3. **עדכון עובדים**
   - שינוי פרטי עובד
   - עדכון תפקידים והרשאות
   - מעקב אחר ביצועים ונוכחות

### פעולות הובלות
1. **יצירת הובלות**
   - הזנת פרטי משלוח הכוללת: מיקומים ופריטים
   - שיבוץ משאית 
   - הגדרת זמני משלוח

2. **ניהול הובלות**
   -  מעקב אחר סטטוס הובלה
   - הוצאת הובלה
   - עדכון פרטי הובלה

3. **ניהול המשאיות**
   - רישום משאיות חדשות
   - מעקב על השימוש והזמינות של המשאיות

4.  **ניהול פריטים**
 - הוספת פריטים חדשים ומשקלם
